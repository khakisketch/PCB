# CircuitEye 웹 시안 (demo2)

PCB 외관검사 웹 MVP **CircuitEye(써킷아이)** 의 리디자인 시안입니다. 단일 HTML 파일(`index.html`)이며 모든 데이터는 가상입니다.

- 이 브랜치(`gh-pages`)는 공개 데모 전용입니다. 기획 문서는 `main` 브랜치에 있습니다.
- 시안의 PCB 사진은 공개 데이터셋(PCB-DSLR · Roboflow · PKU-Market-PCB)에서 고른 것이며 출처와 라이선스는 팀 문서에 정리되어 있습니다.
- 팀: KhakiSketch (충청권 ICT 현장적용 프로젝트 [과제 2])
